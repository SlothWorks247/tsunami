Notes to Sizing/POV

A tool for SA's to enter in notes from various sources and then auto generate a sizing presentation, design document, schema document...

Connect to MongoDB Atlas

Enter your Atlas cluster details to get started. These are saved locally on this machine so you won't need to re-enter them next time you run the app here.
